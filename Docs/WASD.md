# 小车 WASD 模式（2026-11-02）

交付目录为 `D:\竞赛\2026 AIC\2026-AIC`，其余旧副本未修改。使用本目录中的 `上位机/RobStrideConsole.exe` 和 `RobStride05_H743/MDK-ARM/RobStride05_H743.uvprojx`。AXF、HEX、EXE 的固件档案必须配套；连接继续核对完整 Flash。

## 使用

1. 用 Keil 下载本次 `RobStride05_H743` 固件并运行，退出 Debug 释放探针。双击本目录的上位机 EXE，选择原来的调试探针连接，无需新串口或 USB CDC 协议。
2. 按原有流程核对两个 ID，分别选择电机卡片，设置原有速度上限、电流和加速度，完成准备、使能及原有确认。两台保持零速后进入小车模式。
3. 展开“电机控制 → 小车 WASD · 两轮差速模式”。选择哪台为左轮，另一台自动为右轮；按实际安装选择各轮的前进正反方向。默认左轮电机 1 / ID 127 为正转，右轮电机 2 / ID 126 为反转。
4. 输入行驶 / 转向轮速，点击“进入键盘控制”。按住键盘行驶，松键两轮目标归零，沿用原加速度减速。输入框和设置抽屉内的字母不触发运动；焦点进入编辑区域会清除当前按键。

| 按键 | 左右轮动作（安装方向换算前） |
|---|---|
| W / S | 两轮同向前进 / 后退 |
| A / D | 两轮反向，原地左转 / 右转 |
| W+A / W+D | 内轮零速，外轮以所填轮速前进 |
| S+A / S+D | 内外轮按前后与转向分量合成，保持所填外轮轮速 |
| W+S / A+D | 对应相反分量相互抵消 |
| 松开全部方向键 / Space | 两轮目标归零，保持使能 |
| 退出、折叠面板、切换模块、窗口失焦或隐藏页面 | 退出小车模式并请求两轮归零 |
| Esc / 原有“两台全部失能” | 保留原有两台失能请求 |

轮速使用当前上位机范围 0–33 rad/s，换算成各电机有符号目标。单轮目标仍需符合该电机准备时的速度上限；超出时拒绝整对指令并退出模式，不截断数值，也没有另设较低的小车速度上限。原电流限制、加速度、离线/故障/超速保护继续使用。

退出后可继续原独立控制。进入模式时不会自动准备或使能。模式期间准备/使能/独立运行互斥；原有停止、失能、清错可撤销模式并执行。灯效、曲线、CSV、ID 配置和界面设置保留。

## 实现与断连行为

新增 SWD 成对命令区追加在 `g_debug` 末尾，原有成员的类型和偏移保持不变。命令沿用奇数编辑、读回校验、偶数提交和两个服务周期一致性检查。H7 先校验两台状态及各自已有速度上限，再一起更新目标；CAN 仍逐帧使用原仲裁和速度斜坡发送。

浏览器约 180 ms 续发；上位机 650 ms 未收到本控制页面续发时退出。H7 600 ms 未收到有效成对续发时独立退出并将两轮目标置零。任一轮故障也撤销模式、将健康轮目标归零。迟到的速度更新不能重新进入模式。正常退出立即发出归零请求，页面关闭用 keepalive 尽力提交；异常时由这些超时机制处理。该行为以 MCU 电机任务持续运行且 CAN 可用为前提，不代表 MCU 停机或 CAN 断线后的电机侧自停已验证。

原独立电机模式无需续发，继续保持原来的持续运行行为；新增小车超时仅作用于小车模式。时钟、双 Cache 关闭、RTOS 任务、OLED 和灯带配置未改变。
