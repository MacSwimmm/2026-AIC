# 2.1.1 实际帧率与取舍

本版在电脑订阅连续图像时完全停止本机相机预览，只显示操作界面，空闲时不重复重绘。触摸在每次处理循环读取；最后一个电脑订阅断开后自动恢复本机预览。连接期间的标定和图像选点在电脑端完成，沿用 640 × 480 像素坐标。

## 测量方式和结果

实机 MaixCAM Pro，640 × 480，原 YOLO11n 320 × 224 模型，置信度 0.5、IoU 0.45，JPEG 质量 75。电脑通过 USB 网络接收并实际解码 JPEG。以下处理速率按设备帧序号增量 / 实测秒数计算；电脑速率只计不同 `(session_id, seq)`，不将重复图片算作新帧。

| 本轮同场景连续 JPEG 接收并解码（每模式约 20 秒） | 普通模式 | YOLO11 |
|---|---:|---:|
| 修改前 2.1.0，本机约 1 fps 预览 | 29.11 fps | 24.18 fps |
| 修改后 2.1.1，本机仅操作界面 | 29.75 fps | 24.97 fps |

约提高 2.2% / 3.3%，属于小幅收益。上一版本机预览已降为 1 fps，剩余开销主要在采集、推理与 JPEG 编码；不将不同场景、图片大小或浏览器测试的差异全部归因于本机预览。报告见 `performance-controls-before.json` 与 `performance-pc.json`，其中包含对应设备代码哈希。

另在有标定、网格和目标点时复测，见 `performance-calibrated-pc.json`。浏览器实际接收和绘制另计，见 `pc-workflow-validation.json`；设备处理、连续 JPEG 接收、网页绘制三者不能混用。网页分别显示「实际处理 FPS」「电脑显示 FPS」，后者只计成功绘制的不同图像；冻结时显示「已冻结」，停顿时过期采样自动消退。

| 2.1.1 场景 | 普通模式 | YOLO11 |
|---|---:|---:|
| 已标定并保存目标，连续 JPEG 接收与解码 | 29.93 fps | 24.90 fps |
| Windows EXE + Edge，网页实际解码并绘制 | 25.58 fps | 20.79 fps |

标定场景每模式约 15 秒、网页每模式约 5 秒采样；这些是不同负载窗口，不能当作同一次图像处理链路中的每级计数。相机独立处理的速率也不能代替电脑显示速率。

2.1.0 的独立运行结果仍保留在 `performance-standalone.json`，属于历史测量。目标数量、光照、网络和温度变化会影响结果。

**本次没有配置 Wi-Fi，以上不是无线吞吐实测。** 用户后续使用手机热点时，电脑填写相机 Wi-Fi IP，仍使用同一个连续图像接口和设备数据接口。

## 优化内容

- 原先设备 12 fps 上限、电脑 90 ms 取图间隔、网页 110 ms 刷新间隔叠加限制吞吐；现在设备按 30 fps 调度，浏览器随新帧刷新。
- 使用持续 multipart JPEG 连接，每张图片携带自己的识别元数据，减少每帧建立 TCP 连接和新 HTTP 处理线程的开销；接收端不为等待标定状态而暂停视频读取。
- 只保存最新已编码帧，慢客户端跳过旧帧，限制发送缓冲，避免画面持续排队延迟。
- YOLO 使用双缓冲推理。该运行库返回上一输入的结果，因此保留上一输入的完整 RGB 图像与采集时间，将结果、JPEG、坐标严格配对。没有用上一帧检测框覆盖下一帧画面。
- 已用 120 次随机交替的空白/已知物体图片及随机调用间隔，比对同步推理结果，确认一帧延后的配对规律；记录见 `nn-pairing-validation.json`。
- 本机按钮、页眉/页脚和标定网格缓存；网格只在标定/目标修订改变时栅格化，不在每帧重画数百条线。
- 没有电脑订阅时暂停连续网络 JPEG 编码；屏幕检查 JPEG 按请求生成。启动第一帧先保留原先的 JPEG/显示资源初始化顺序。
- 电脑连接时，本机不缩放相机图像、不叠加网格/检测框、不显示实时或冻结预览；操作界面仅在触摸、数据修订或操作状态变化时重绘。识别菜单、目标列表与网络地址仍可操作。断开电脑后恢复本机画面、触屏标定和选点；独立 YOLO 预览上限 8 fps。

完整 640 × 480 标定图像、像素坐标系、镜头校正与单应性算法、原检测阈值、模型与检测输入尺寸都保留。AprilTag 与红色标记功能保留，仍按原来的像素缩放规则输出。

## YOLO 选择和后续无线使用

原本点击显示“普通画面”等当前模式的按钮会循环切换，入口不直观；触摸又跟随低帧率重绘读取。现在使用独立「识别模式 ›」菜单，明确选择四种模式，触摸轮询与屏幕重绘分开；重启不会因电脑重连而重置模式。

相机的「电脑连接」页显示 Wi-Fi/USB 地址。电脑与相机连接同一手机热点后，在上位机「设备连接设置」填 Wi-Fi IP。电脑的标定、选点、校验、目标管理、导入导出均操作相机上的同一份持久化数据。断开电脑后设备继续运行。

```powershell
python tools/check_performance.py --seconds 20 --output docs/performance-pc.json
python tools/check_native.py --performance
python tools/check_pc_workflow.py
python tools/check_controls.py
python tools/check_stability.py --duration 120
```

独立运行测速时关闭其他电脑取图连接。触屏/网页标定流程工具只在设备没有正式标定与目标时运行，创建并清理自己的合成数据。坐标正确性检查不代表实际场地误差已经重新测量。
