CALIBRATION / 单位：米

确定你的地面区域

按实际矩形边界依次点 A → B → C → D。A 是原点，AB 是 X 方向，AD 是 Y 方向。

  1. A · 原点 (0, 0)
  2. B · X 端 (宽度, 0)
  3. C · 对角 (宽度, 长度)
  4. D · Y 端 (0, 长度)

DETECTION / 实机识别

自动获取目标位置

YOLO 的位置取识别框底边中心，是落地位置的近似。色块和标签的中心需要实际放在标定平面上。

暂无识别结果

模型未覆盖的自制小车或物品，可能需要专门训练；本功能不会把所有物体自动变成避障地图。

VALIDATION / 独立实测点

测一下实际误差

在地面选一个已量好坐标的点（避开四个角点），点击画面，再填入实测值。

还没有独立实测点

建议在近处、远处、四周及中间分别测点，关注最大误差。这里显示的是你录入的实测结果。
